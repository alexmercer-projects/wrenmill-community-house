# Wrenmill Community House

A one-page homepage for a made-up small-town nonprofit and community hall. It shows this week's events, ongoing programs, hall rental, volunteer sign-up, and a donate block.

This is a concept demo. Wrenmill Community House is not a real organization. The town, events, and contact details are placeholders.

## View it

Live demo: https://alexmercer-projects.github.io/wrenmill-community-house/

Or open `docs/index.html` in a browser. There is no build step.

## Tech

HTML and CSS. Fonts are Crimson Pro and Libre Franklin, in `docs/fonts/`.
